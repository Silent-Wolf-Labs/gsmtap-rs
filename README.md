# GSMTAP Rust Implementation

This repository contains a clean Rust implementation of a GSMTAP packet parser and encoder.

## Repository Structure

- `src/` - Source code for the GSMTAP implementation
- `tests/` - Unit tests for the implementation

## Building

To build the project, run:

```bash
cargo build
```

## Testing

To run tests, execute:

```bash
cargo test
```

## Reference implementation

The reference implementation is located at `../libosmocore` and is read-only. It is not a build-time or runtime dependency of this project.
