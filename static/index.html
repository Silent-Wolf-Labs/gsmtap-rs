Hexparse

Parse hexadecimal text into bytes. Hex source format lets you supply exact input bytes.

BCD

Convert digit strings and BCD bytes, or individual characters and nibbles. Nibble offsets start with the low nibble.

Use hex source format for BCD bytes. Character-to-nibble maps unsupported bytes to 0. Decoding reports the requested digit count even when the text is truncated.

Bits

Pack byte-sized bits or unpack packed bytes. For byte-sized bits, use source bytes such as 00 01 01 00.

For packing, you can also choose Unpacked bits and enter 0110. Basic packing shifts raw byte values; extended packing treats nonzero bytes as 1.

Pack offsets: input in bytes, output in bits. Unpack offsets: input in bits, output in bytes.

Base64

Encode bytes, decode Base64, or probe decoded size.
